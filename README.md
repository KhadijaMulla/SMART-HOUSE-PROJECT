# 🏠 SmartHouse – Smart Rental & Roommate Management System

SmartHouse is a web-based rental management platform designed to simplify
property discovery, rental requests, and communication between students and
property owners.

## 🚀 Features

- 👤 Student and Owner roles
- 🔐 Secure authentication using Spring Security & JWT
- 🏠 Property listing and management
- 📩 Rental request management
- ⭐ Property reviews and ratings
- 🔎 Property search and filtering
- ❤️ Favourite properties
- 📱 Responsive frontend
- 🌐 RESTful APIs
